### 📈 SaaS Growth Leak Finder

**PostgreSQL · SQL · Excel · Power BI**

A SaaS analytics project designed to identify **customer funnel drop-offs, engagement gaps, churn patterns, and potential revenue leakage**.

```text
Acquisition
     ↓
Signup
     ↓
Activation
     ↓
Subscription
     ↓
Revenue
     ↓
Engagement
     ↓
Churn
```

**Key Analysis**

* 👤 User acquisition performance
* 🔄 Activation & trial conversion
* 💳 Paid subscription rate
* 💰 Monthly Recurring Revenue (MRR)
* 📊 Average Revenue Per User (ARPU)
* 📉 Customer churn
* 📦 Revenue by subscription plan
* 📣 Acquisition channel performance
* ⚡ Product engagement

**Key Work**

* Analyzed **50,000 customer records across four relational tables**
* Performed data quality checks and validation
* Used SQL to analyze the complete SaaS funnel
* Applied joins, CTEs, aggregations, and window functions
* Analyzed MRR, ARPU, conversion, and churn
* Validated results using Excel Pivot Tables
* Built an interactive Power BI dashboard
* Translated findings into actionable business insights

**Tech:** `PostgreSQL` `SQL` `Excel` `Power BI`

🔗 **[View Project →](https://github.com/marmikapimparkar)**
